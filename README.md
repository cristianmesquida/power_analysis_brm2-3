# Repository content

This repository contains materials used for Power Analysis (Lectures 1) in Behavioral Research Methods (BRM) 2 and 3

# Repository structure

```markdown
power_analysis/
├─ lecture/
|   sample_size_justification.qmd: Quarto file containing content, code and data to generate "sample_size_justification.html".
|   sample_size_justification.html: The HTML output of "sample_size_justification.qmd". 
|   figures/: Folder containing figures used in "sample_size_justification.qmd".
└─ exercises/: Folder containing practice exercises
```

# How to use this project:

Download the project, open the R project, then lectures/sample_size_justification.qmd and click Render. 
This will open the slides in your browser, where you can navigate through them.
